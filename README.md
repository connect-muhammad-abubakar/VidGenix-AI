# 🎬 VidGenix AI

### Build Videos Without Editing — Just One Script!

VidGenix AI is a powerful AI video generation tool that turns 
your script into a fully produced video automatically.

## Features
- ✅ AI Script Generation
- ✅ Automatic Voiceover (TTS)
- ✅ HD Stock Footage
- ✅ Animated Subtitles
- ✅ Background Music
- ✅ 1080p Video Output
- ✅ No editing skills needed!

## How to Use
1. Run start.bat (Windows) or python3 main.py (Linux)
2. Open browser at http://127.0.0.1:8501
3. Enter your script
4. Click Generate
5. Download your video!
